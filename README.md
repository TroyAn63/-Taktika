## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в Chrome, Edge, Firefox или Safari.
3. Для публикации в интернете загрузите **всю папку проекта**, сохраняя структуру каталогов.

## Что уже изменено в этой версии?
- HTML, CSS и JavaScript вынесены в отдельные файлы.
- Сохранён классический режим подключения JavaScript: это важно, потому что текущий интерфейс использует HTML-обработчики `onclick` и общие глобальные функции.
- Добавлены новые постройки, правила вместимости башни, непроходимость рва и индивидуальная видимость для каждой цивилизации.
- Убрано запрещение масштабирования страницы через жесты браузера.
- Добавлены улучшения мобильной раскладки, сенсорных размеров кнопок, безопасных отступов и альбомной ориентации.

## Важно
Это продолжающаяся разработка. JavaScript проверен на синтаксические ошибки, а ключевые правила строительства и радиусы обзора проверены отдельными логическими тестами. Полный игровой прогон в браузере на этом этапе ещё нужно выполнить на твоём устройстве.
В дальнейшем код можно будет разделить на отдельные логические модули, постепенно заменяя глобальные связи без поломки игры.

## Структура
- `index.html` — разметка игрового интерфейса.
- `css/game.css` — оформление и адаптивная раскладка.
- `js/game.js` — игровая логика.
- `assets/` — папка для будущих изображений, звуков и других ресурсов.

## Этап 2: постройки и туман войны

- Рабочий может начать строительство наблюдательной башни (300 золота, 10 ходов) или рва (50 золота, 5 ходов). Для этого выберите отряд с рабочим, затем самого рабочего в списке окна «Армия».
- Башня занимает клетку, даёт обзор на 4 клетки и вмещает до 2 юнитов. Юниты могут входить в неё и выходить из неё обычным перемещением.
- Ров занимает клетку, даёт обзор на 1 клетку и непроходим для всех юнитов. При завершении строительства рабочий автоматически отходит на свободную соседнюю клетку; поэтому перед началом строительства такая клетка должна быть свободна.
- Рабочий может разрушать соседние башни и рвы. Разрушение рва стоит 50 золота; разрушение башни — без оплаты, поскольку отдельная стоимость не была задана.
- Крепости и башни дают обзор на 4 клетки, города — на 5, обычные юниты — на 2, разведчики — на 4.
- Соперники действуют по собственной видимости: скрытые от них войска и города не выбираются целями для атак и преследования.
- Неосвещённые клетки затемнены; объекты и юниты за пределами текущего обзора не отображаются.

Сохранения включают новые постройки и прогресс их строительства. Старые сохранения продолжают загружаться без построек.


## Этап 3 — Армии, реки и разрушение рвов
- Добавлена технология «Военное Искусство»; для её открытия нужны «Военная тактика» и «Денежное обращение».
- Создание Армии доступно после изучения технологии. Для создания нужно переместить одиночный юнит на клетку с другим одиночным юнитом. Игра спрашивает подтверждение и позволяет задать название.
- Над армиями отображается развевающийся флаг цвета владельца.
- Река анимирована; речные клетки непроходимы для всех юнитов, переправа возможна только по мостам.
- Разрушение рва рабочим занимает 5 ходов (50 золота оплачивается при начале работ). Другие сооружения разрушаются за 1 ход.
- Постройки отображаются поверх гарнизона.


## Этап 4 — боковая панель интерфейса
- На широких экранах игровое поле располагается слева, панель хода, технологий, меню, сил и журнала действий — справа.
- Панель можно скрыть кнопкой «Скрыть панель» и вернуть кнопкой «Панель».
- На узких экранах панель открывается выдвижным окном.
